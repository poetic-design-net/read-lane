# Beispielarchitektur

Dieses Dokument kann mit dem CLI veröffentlicht werden:

```bash
readlane push examples/sample.md --open
```

## Überblick

- Projekte organisieren Dokumente
- CLI synchronisiert Markdown aus dem Repository
- Share-Links bleiben stabil bei Updates

## Nächste Schritte

1. `readlane login`
2. `readlane init`
3. `readlane push --all`
